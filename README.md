# Arctis Vision — Website

Digitale Betriebssysteme für Restaurants, Friseure und Dienstleister.

## Dateien
- `index.html` — Startseite
- `impressum.html` — Impressum (Platzhalter ausfüllen!)
- `datenschutz.html` — Datenschutzerklärung (Platzhalter ausfüllen!)

## Auf GitHub Pages veröffentlichen
1. Neues Repository anlegen (z. B. `arctis-vision`).
2. Diese drei Dateien + README hochladen (Add file → Upload files → Commit).
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/root` → Save.
4. Nach ~1 Min ist die Seite live unter `https://<dein-name>.github.io/arctis-vision/`.

## Vor dem Livegang
Alle **violett markierten Platzhalter** in Impressum & Datenschutz durch echte Daten ersetzen
(Anschrift, Telefon, E-Mail). Eigene Domain? Dann in den `mailto:`-Links die E-Mail anpassen.
